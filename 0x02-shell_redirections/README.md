# 0x02. Shell, I/O Redirections and Filters

This project introduces basic input and output redirections and essential text-processing commands in Linux. It focuses on controlling command output, reading input from files, managing errors, and combining commands using pipes for efficient data processing.

---

## 🧠 Learning Objectives

By completing this project, I learned how to:

- Redirect standard output using `>` and `>>`
- Redirect standard input using `<`
- Redirect error output using `2>` and `&>`
- Use pipes `|` to chain commands
- Work with common Linux filters such as:
  - `cat`
  - `head`
  - `tail`
  - `sort`
  - `uniq`
